# Grain List Working Agreement

- Preserve the approved light-gray map, clean sans-serif branding, circular
  markers, and original profile popup styling.
- Before changing the visual direction, produce mockups and obtain explicit
  user approval. A generic request to continue is not redesign approval.
- Organization URLs must open profiles above the map, including direct visits,
  refresh, and browser Back/Forward. Preserve readable static HTML for indexing.
- Sidebar records must follow the visible map area automatically.
- Do not add paid services or consume API credits without explicit approval.
- Treat the reviewed source Sheet as authoritative. Keep stable record IDs and
  review imported changes before publishing; do not fabricate missing values.
