# Data Quality Policy

## Evidence

Publish a value only when a reliable source supports it. Prefer the current
organization website, then current social accounts, industry directories,
recent reporting, and other clearly attributable sources. A blank means no
reliable source was found; it is not an estimate.

## Review

- New values and replacements require a source.
- Function and Grains are additive lists unless a reviewed correction replaces
  a generic grain with a more specific variety.
- Duplicate candidates and operating status are reviewed before publication.
- Organizations reviewed as closed are excluded from the public export.
- Public submissions are suggestions, not automatic edits.

## Public-data safeguards

- The browser dataset uses opaque public identifiers rather than internal IDs.
- Confidence scores, notes, review history, and private source files are never
  published.
- Only controlled Function values are accepted.
- Organizations without reliable coordinates remain searchable without an
  estimated map pin.
- Every release passes automated tests and public-data validation.
